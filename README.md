# HAUNT

React/Vite PWA prototype for goth discovery, style and community. The current source includes local saved items/preferences and mock community content; it is not evidence of a connected production backend.

See [SESSION-HANDOFF.md](SESSION-HANDOFF.md) for the inspected implementation, pending work and shared session update template. Read [AGENTS.md](AGENTS.md) before changes.

## Local development

Use the existing package manifest and lockfile. Available scripts: `npm run dev`, `npm run build`, `npm run preview`, and `npm run lint`. No build or browser checks were rerun for the continuity rollout.
